# Guia do Volume 02

## O que é este volume?

O **Volume 02 — Frontend Profissional com React e Next.js** é o segundo livro da Stackovia Learning Series: uma série de 11 volumes que leva você do zero ao sistema real, com portfólio profissional em cada etapa.

Este volume pega o IntraStack básico (site estático HTML/CSS/JS do Volume 01) e o transforma em um app React/Next.js profissional com:

- Projeto Next.js configurado com TypeScript e Tailwind CSS.
- Componentes reutilizáveis com props tipadas.
- Rotas com o App Router do Next.js.
- Formulários com validação real.
- Autenticação com NextAuth.js (introdução).
- Deploy na Vercel com domínio customizável.
- Portfólio público com README profissional.

## Como usar este material

Cada capítulo é autossuficiente, mas foi projetado para ser lido em ordem. O projeto integrador — o **IntraStack App** — cresce capítulo a capítulo.

**Pré-requisito:** ter concluído o Volume 01 ou dominar o equivalente (terminal, Git, GitHub, HTML/CSS/JS básico, publicação estática).

**Leia no ritmo que fizer sentido para você.** A cadência depende do seu nível de experiência e quanto tempo você dedica aos exercícios "Mãos à Obra".

**Execute os exercícios "Mãos à Obra"** antes de avançar. Sem executar, você leu sobre o assunto — mas ainda não tem evidência de que sabe fazer.

**Crie os artefatos de portfólio** (README, componentes documentados, screenshots, posts LinkedIn). Eles são a diferença entre "estudei React" e "posso mostrar que sei construir com React".

## O universo Stackovia

A **Stackovia** é uma software house fictícia onde você é desenvolvedor júnior de frontend. O **Mestre Py** continua como mentor técnico: faz perguntas incômodas na hora certa e não deixa você confundir "componente que renderiza" com "componente que escala".

Os problemas de negócio são fictícios, mas as ferramentas e os erros são reais.

## Rótulo de maturidade

Este volume é publicado progressivamente. Cada capítulo exibe um rótulo:

- **Preview** — capítulo revisado editorialmente, disponível para leitura e feedback.
- **Em produção** — capítulo em desenvolvimento ou revisão.

Nenhum capítulo é publicado como Preview sem passar pelo ciclo: contrato → rascunho → auditoria → revisado v1.0.

## Stack do volume

- **Framework:** Next.js 14+ (App Router)
- **Linguagem:** TypeScript
- **Estilo:** Tailwind CSS + shadcn/ui
- **Gerenciador de pacotes:** npm
- **Deploy:** Vercel (introdução)
- **Controle de versão:** Git + GitHub
