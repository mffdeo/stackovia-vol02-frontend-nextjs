## Sobre este volume

Você vai evoluir o IntraStack básico (site estático HTML/CSS/JS do Volume 01) para um app React/Next.js com componentes reutilizáveis, rotas reais e deploy profissional na Vercel.

**Pré-requisito:** Volume 01 ou equivalente (terminal, Git, GitHub, HTML/CSS/JS básico).

## Projeto integrador

**IntraStack App** — o IntraStack básico reconstruído como app React/Next.js ao longo dos 14 capítulos.

O código de referência será publicado ao final do volume.

## Como usar

Leia os capítulos em ordem. Execute os exercícios "Mãos à Obra". Crie os artefatos de portfólio antes de avançar.
