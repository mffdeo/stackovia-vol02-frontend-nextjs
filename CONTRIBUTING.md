# Contribuindo

## Problemas encontrados

Abra uma issue descrevendo:
- Qual capítulo e seção.
- Qual é o problema (erro técnico, typo, link quebrado, conceito impreciso).
- Sugestão de correção, se tiver.

## O que não aceitamos por PR

- Alterações de conteúdo conceitual (decisão editorial).
- Adição de capítulos novos (o conteúdo vem do repositório de autoria).
- Mudanças na stack ou no escopo do volume.

## Traduções

Abra uma issue antes de começar qualquer tradução para alinhar o escopo e evitar esforço duplicado.
